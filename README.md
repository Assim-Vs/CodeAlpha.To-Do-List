# To-Do List Web App

A **full-featured web-based To-Do List** application built with HTML, CSS, and JavaScript.  
Manage your daily tasks efficiently with features like due dates, priority, filters, and localStorage persistence.

---

## 🚀 Features

- Add new tasks with **task name, due date, and priority** (High, Medium, Low)  
- Mark tasks as **completed**  
- **Edit** and **delete** tasks  
- **Filter tasks** by status (All, Completed, Pending) and priority  
- **Persistent storage** using `localStorage` – tasks stay even after page refresh  

---

## 💻 Tech Stack

- **HTML** – for structure and input forms  
- **CSS** – for styling and layout  
- **JavaScript** – for task logic, CRUD operations, event handling, and localStorage  

---

## 📌 Key Concepts

- **CRUD operations** in JavaScript: Create, Read, Update, Delete tasks  
- **Event handling**: submit, click events  
- **DOM manipulation**: dynamically render tasks  
- **LocalStorage**: persist tasks in the browser  
- **Filters**: show tasks based on status or priority
